# Md Imranul Islam — professional portfolio

## Publish
1. Create a public GitHub repository named `YOURUSERNAME.github.io`.
2. Upload `index.html` and `robots.txt` to its root.
3. In repository Settings → Pages, choose Deploy from branch (main/root).
4. Visit https://YOURUSERNAME.github.io after deployment.
5. Add your live URL to your LinkedIn contact details and featured section.
6. Open https://search.google.com/search-console and verify ownership, inspect your live URL, and request indexing.

## SEO after choosing a permanent URL
- Add `<link rel="canonical" href="https://YOURDOMAIN/">` in `<head>`.
- Add `<meta property="og:url" content="https://YOURDOMAIN/">` in `<head>`.
- Replace YOURDOMAIN in sitemap.xml with your actual public host, then upload sitemap.xml.
- Add `Sitemap: https://YOURDOMAIN/sitemap.xml` to robots.txt.
- Submit sitemap.xml in Google Search Console.

## Verify before publishing
- Exact Finnish entrepreneurship qualification name and awarding institution.
- CTO responsibilities and employment dates.
- Research description and degree dates.
- Add a professional photograph only with your permission.
- Optional: public email address and GitHub links.

This is a static HTML website, with no database or analytics. Google indexing is not guaranteed.
